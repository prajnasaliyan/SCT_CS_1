# SCT_CS_1
Caesar Cipher Encryption and Decryption

This is a simple Python program that performs encryption and decryption using the Caesar Cipher technique.
The Caesar Cipher is one of the earliest and simplest methods of encrypting text, where each letter in the plaintext is shifted by a certain number of positions in the alphabet.

Features

Encrypts any text using a shift value.

Decrypts the encrypted text automatically.

Handles both uppercase and lowercase letters.

Non-alphabet characters (like numbers or punctuation) remain unchanged.

 How It Works

The user enters a message and a shift value (number).

Each letter in the message is shifted by that number in the alphabet.

To decrypt, the program simply reverses the shift.
